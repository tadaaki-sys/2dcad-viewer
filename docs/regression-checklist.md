# 回帰テストの手順書

2D CAD Viewer の既存機能が壊れていないことを、各 Phase の完了前に確認するための手順です。
「壊れたらすぐ気づく」ことが目的で、実行は `npm run regression` の1コマンドです。

## 1. 実行方法

```
npm run regression
```

次を順に実行し、1つでも失敗したら止まります。

| 順 | 内容 | 確認すること |
|---|---|---|
| 1 | 型チェック(アプリ、E2E) | 型のエラーがないこと |
| 2 | 単体テストと回帰テスト(`vitest`) | 読み込み・描画命令・選択・スナップ・カメラ・レイヤー表示・全体表示が、基準のとおりであること。**実図面と性能もここで確認する** |
| 3 | E2E(`playwright`) | ブラウザの実際の操作(下の表)が、基準のとおりであること |

個別に実行するとき:

| コマンド | 内容 |
|---|---|
| `npm test` | 単体テストと、見本図面の回帰テスト(速い。実図面と性能は含まない) |
| `npm run e2e` | E2E だけ |
| `npm run regression` | すべて(実図面と性能を含む。DWG の変換があるので数分かかる) |

## 2. 自動で確認していること

### 見本図面の回帰テスト(`src/regression/viewer.regression.test.ts`)

見本図面は `src/regression/fixtures.ts` にあります(架空の工場レイアウト。実図面は使いません)。

- DXF の読み込み: 図形の種類別の数、座標、レイヤー、色、線種、線幅、点の設定
- ブロックの展開(通常、鏡像、配列、入れ子の深さ)、寸法、ポリラインの円弧(膨らみ)
- 未対応の図形の数え上げ(ほかの図形は消えない)
- レイヤーの OFF・フリーズが初期状態で非表示になること
- 描画命令(色ごとのまとまり、破線、太線、点の記号)と、非表示のレイヤーを描かないこと
- 空間索引を使っても使わなくても、同じ結果になること
- 選択(クリック、窓、交差)とスナップ(端点、中点、交点、最近点)
- カメラ(ズーム、全体表示)と、表示中のレイヤーだけで全体表示すること

### E2E(`e2e/viewer.e2e.ts`)

| 操作 | 確認すること |
|---|---|
| 図面を開く | 描画される、レイヤー一覧、OFF・フリーズが未チェック、未対応の件数 |
| 図面を閉じる・開き直す | 開始画面に戻り、別の図面を開ける |
| ホイールでズーム | カーソル直下の点が動かない |
| Space＋ドラッグ、中ボタンのドラッグ | 動かした量だけ表示が動く |
| 全体表示のボタンと `f` キー | 初期表示の倍率に戻る。非表示のレイヤーは範囲に含めない |
| レイヤーのチェック | 線の表示・非表示が切り替わる |
| クリックでの選択、Ctrl で追加、Esc で解除 | プロパティ欄の表示 |
| 窓選択(左→右)、交差選択(右→左) | 完全に含まれたものだけ／触れたものも選ばれる |
| 測定(`m` キー) | 端点に吸い付いた正確な距離、線への吸着、削除、Esc で終了 |

### E2E(`e2e/commands.e2e.ts`、Phase 2)

| 操作 | 確認すること |
|---|---|
| コマンドライン | 図面の下に表示される。Enter キーで入力欄へ移る。`fit`・`measure`・`m`・`di`・`close` が動く。知らない名前は「不明なコマンド」と表示 |
| ↑↓ | 履歴をたどり、↓ で入力中だった文字に戻る |
| 入力欄での `f`・`m`・Backspace | ショートカットとして動かない(全体表示・測定・測定結果の削除が起きない) |
| ツールバー、`f`・`m` キー、Esc | 今までと同じに動く。実行中のコマンドがあるときの Esc は、コマンドの取り消しだけ。次の Esc で測定を抜ける |
| コマンドが動いていないときの、入力欄での Esc | 入力した文字を消して、入力欄から出るだけ(測定は続く)。次の Esc(入力欄の外)で測定を抜ける |
| ツールバーのボタンをマウスで押したあと | 次の Enter は、ボタンの再実行ではなく、コマンドラインへ移る |
| `id`(点の座標を表示) | 図面のクリック(端点に吸着)、`1000,500`・`@500,0`・全角の `＠１００＜９０` で入力できる。誤った入力は理由を表示して待ち続ける |
| 点を待っている間のクリック | 図形の選択にも、測定の開始にもならない。終われば元に戻る |
| 図面を閉じる・開き直す | 実行中のコマンドは持ち越さない |

### E2E(`e2e/undo.e2e.ts`、Phase 3)

編集のコマンドはまだ無いので、開発サーバー専用の入口(`window.__cadDev`)で図形を変更して確かめる。

| 操作 | 確認すること |
|---|---|
| 履歴が空のときの Ctrl+Z・Ctrl+Y・Ctrl+Shift+Z、`undo`・`redo` | 「元に戻す操作がありません」「やり直す操作がありません」と表示され、図面は変わらない |
| 線の追加 → Ctrl+Z → Ctrl+Y(Ctrl+Shift+Z も) | 表示される → 消える → 戻る。`u` は `undo` の別名 |
| 拡大・移動してから、変更・Undo・Redo | 表示の位置と倍率が動かない(全体表示に戻らない) |
| 複数の変更を Undo | 新しいものから1つずつ戻る |
| 取り込んだ図形(外枠)の削除、線の移動(置き換え)の Undo | 元の位置に戻る |
| 選択中の図形が Undo で消える | 選択から外れる。Redo で戻っても選択には戻らない。関係ない選択は残る |
| 入力欄での Ctrl+Z | 図面は戻らない |
| `id` が点を待っている間の Ctrl+Z | 無視される。Esc で取り消したあとは動く |
| 図面を閉じて開き直す | 履歴は捨てられる |

### E2E(`e2e/draw.e2e.ts`、Phase 4)

| 操作 | 確認すること |
|---|---|
| `line`(`l`)でクリックして描く。Enter・Esc で終了 | 現在のレイヤーの色で描かれる。2本以上描いても、1回の Ctrl+Z で全部戻る |
| 作図中のカーソル移動 | 白い破線のゴム紐が出て、終了すると消える |
| 座標入力(`550,50`・`@200,0`・`@0,-20`) | 絶対・相対の点で描ける |
| `u`、作図中の Ctrl+Z(入力欄の中でも) | 1点戻る。相対入力の基準も戻る |
| ツールバーの別のコマンドに切り替える | 描いた分は失われず、確定される |
| `pl`(PLINE)、`c` | 1本のポリライン(3点、閉じる)。選ぶと LWPOLYLINE と表示 |
| `rect`(`rec`) | 2つの角(クリック、または `@100,40`)で長方形。幅か高さが0なら、理由を表示して待つ |
| レイヤー欄の「現在」のラジオボタン | ステータスバーに表示。新しい図面を開くと、レイヤー `0` に戻る |
| 現在のレイヤーが非表示(OFF) | `line`・`rect` は始まらず、理由を表示する |
| ツールバーの「元に戻す」「やり直し」 | 履歴がないと無効。押すと戻る・やり直す |
| `tofront`・`toback` | 選択中の、新しく描いた図形だけが、描画順の最前面・最背面へ。Ctrl+Z で戻る。取り込んだ図形を選んでいるときは、理由を表示する |
| 変更したあとの表示 | 「未保存の変更あり」。開いた直後の状態まで Ctrl+Z で戻すと消える |
| 未保存のまま、図面を閉じる・`close`・`open`・ページを閉じる | 確認が出る。キャンセルすれば閉じない |
| 作図の途中(2点以上)で、図面を閉じる | 描きかけの線が確定されたうえで、確認が出る(確認なしには閉じない)。ページを閉じる・再読み込みでも、確認が出る |
| 作図中、入力欄に座標を打ちかけたまま、図面をクリックする | 打ちかけの文字は消える(案内の文が同じ段階でも) |
| `rect` で、空のEnter | 図形を作らずに終了する |
| 新しい図面を読み込んでいる間 | 作図は始まらず、元に戻す・やり直しは「読み込み中」と表示して何もしない |

### 本番ビルドの確認(Phase 3 から)

開発用の入口が、本番に入っていないこと。

```
npm run build
```

ビルド後、`dist` の中を `__cadDev`・`devHooks` で検索して、**0件**であること(`元に戻す操作がありません` は、1件以上あること)。

### 実図面(手元だけ)

`regression-local/` フォルダー(git の管理外)に置きます。

- `manifest.json`: 対象の図面の名前とパスの一覧
- `golden/<名前>.json`: 基準値(図形の種類別の数、範囲、レイヤー数、座標のハッシュ)
- `perf/` と `perf-baseline/`: 性能の測定結果と基準値

初回は基準値を作って終わります。2回目以降は、基準値と比べます。
**図面を追加するとき:** `manifest.json` に1行足して、`npm run regression` を実行します(基準値が自動で作られます)。
**性能:** 基準の2倍(+20ms)を超えると、失敗にはせず警告を出します。

## 3. 基準値を更新するとき(承認が必要)

意図して挙動を変えたときだけ、基準値を更新します。**更新は、事前に承認を取ってから行います。**

| 対象 | 更新のしかた |
|---|---|
| 見本図面のスナップショット | `npx vitest run src/regression -u` |
| 実図面と性能の基準値 | `CAD_REGRESSION_UPDATE=1`(PowerShell: `$env:CAD_REGRESSION_UPDATE="1"`)を付けて `npm run regression` |

## 4. 自動では確認できないこと(Phase の完了前に目で確認する)

- Undo・Redo の時間(実図面。`src/regression/undo.perf.regression.test.ts` が測り、`regression-local/perf/<名前>.undo.json` に残す。時間では失敗にしないので、結果を目で確認する)

- 実図面を CAD ソフトで開いた見え方と、ビューアの見え方が一致するか(特に、最近直した鏡像、円弧の膨らみ、レイヤー "0" の継承、点)
- 大きな図面での、操作の軽さの体感(ズーム、パン、選択)
- DWG の読み込み(HH のような一部の2010形式は、30〜50秒かかる。「このまま」と決定済み)

## 5. うまく動かないとき

| 症状 | 対処 |
|---|---|
| E2E で Chrome が起動直後に終了する(終了コード 3221225477) | `playwright.config.ts` に、起動オプションの設定を入れてあります(このPCの Chrome 156 と Playwright 1.64.1 の組み合わせで必要)。Chrome や Playwright を更新したときは、この設定が不要になっていないか確認します。 |
| E2E の最初のテストだけ遅い | 開発サーバーの初回の準備です。再実行すれば速くなります。 |
| ポート 5174 が使われている | 別の開発サーバーが動いています。止めてから実行します。 |
